A modern, responsive website concept for residential, commercial, and emergency electrical services across New York.

Built with **React, TypeScript, Vite, and Tailwind CSS**, featuring interactive quote generation, service showcases, project case studies, and a polished user experience.

## ✨ Key Features

- ⚡ **Interactive Quote Generator** — Multi-step quote requests with preliminary estimates.
- 🏠 **Residential & Commercial Services** — Dedicated service pages for different electrical needs.
- 🚨 **Emergency Electrical Services** — Prominent emergency contact and click-to-call actions.
- 💡 **Lighting & Rewiring** — Service information for modern lighting, wiring, and rewiring.
- 🛡️ **Electrical Safety** — Inspection information and electrical code compliance guidance.
- 📰 **Knowledge Hub** — Searchable articles covering electrical safety and maintenance.
- 🏗️ **Project Showcase** — Case studies highlighting electrical installations and upgrades.
- ⭐ **Customer Reviews** — Review interfaces and customer feedback presentation.
- 🔎 **Dynamic SEO** — Page metadata, Open Graph tags, and structured data support.
- 📱 **Responsive Design** — Mobile-first layouts with smooth transitions and accessible controls.

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| React 18 | Component-based user interface |
| TypeScript | Type safety and maintainable code |
| Vite | Fast development and production builds |
| Tailwind CSS | Responsive styling and design system |
| Lucide React | Lightweight SVG icons |
| Google Fonts | Plus Jakarta Sans and Caveat typography |
| Schema.org JSON-LD | Structured data for search engines |
| Custom SEO Hook | Dynamic page metadata management |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/GhousDeveloper/cosper-electrical-expert-website.git

# Navigate to the project
cd cosper-electrical-expert-website

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the local development URL displayed in your terminal.
